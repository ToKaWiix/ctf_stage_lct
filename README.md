# CTF Challenge - Plateforme

## Description

Cette plateforme est un projet de Capture The Flag (CTF) développé en PHP orienté objet avec architecture MVC.  
Elle permet la gestion des joueurs, l’affichage des scores, la soumission de réponses via QR codes, ainsi qu’une administration simple.

---

## Structure du projet

- **app/**  
  Contient les contrôleurs, modèles, vues, et le cœur de l’application (MVC).

- **config/**  
  Fichiers de configuration (base de données, paramètres divers).

- **public/**  
  Point d’entrée public (index.php) et ressources accessibles (CSS, JS, images).

- **vendor/**  
  Dépendances gérées par Composer.
